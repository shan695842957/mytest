## 🚀 快速开始

### 1. 启动后端
```bash
cd backend
./start.sh
```

### 2. 启动前端
```bash
cd frontend
npm run dev
```

### 3. 访问系统
```
http://localhost:5173
```

### 4. 登录测试
使用内置账号：
- 开发者: `admin_developer` / `Admin@123`
- 运维者: `admin_operator` / `Admin@123`
- 用户: `admin_user` / `Admin@123`

## 🔐 权限控制

### 权限矩阵

| 功能 | Developer | Operator | User |
|------|-----------|----------|------|
| 查看用户列表 | ✅ | ✅ | ❌ |
| 创建用户 | ✅ | ✅ | ❌ |
| 编辑用户 | ✅（所有） | ✅（限制） | ❌ |
| 删除用户 | ✅（所有） | ✅（限制） | ❌ |
| 修改密码 | ✅（所有） | ✅（限制） | ✅（自己） |
| 查看审计日志 | ✅ | ✅ | ❌ |
| 系统设置 | ✅ | ❌ | ❌ |

### 权限规则（完全对应后端）

1. **高角色管理低角色**
   - Developer > Operator > User

2. **内置账号特殊规则**
   - 内置账号不可删除
   - 内置账号可管理同级别

3. **自我保护**
   - 不能删除自己
   - 不能更新自己（使用个人中心）

```tsx

```

### 权限控制
```tsx
// 组件级
<AuthGuard roles={[UserRole.DEVELOPER]}>
  <Button>删除</Button>
</AuthGuard>

// Hook 方式
const { isDeveloper } = useAuth()
{isDeveloper && <Button>删除</Button>}
```
