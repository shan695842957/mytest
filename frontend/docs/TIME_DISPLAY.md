# 顶部时间显示组件

## 📍 位置

登录后的主布局顶部工具栏，位于主题切换按钮左侧

```
┌────────────────────────────────────────────────┐
│ 🏠 面包屑     [时间] 🎨 🌓 🌍 👤              │
│               ↑ 新增                            │
└────────────────────────────────────────────────┘
```

## 🎨 视觉设计

### 布局结构
```
┌──────────────────────────────────────────┐
│ 🕐  17:45:32              UTC+8          │
│     2025年11月07日 周四                  │
└──────────────────────────────────────────┘
```

### 组件层次
```
[容器]
  ├─ [Clock 图标] - 主题色
  ├─ [时间信息区]
  │   ├─ 17:45:32 - 加粗、等宽字体
  │   └─ 2025年11月07日 周四 - 小字、次要色
  └─ [时区徽章] UTC+8 - 主题色背景
```

## 📊 技术实现

### 1. 实时更新机制
```typescript
// 每秒更新一次
useEffect(() => {
  const timer = setInterval(() => {
    setCurrentTime(new Date())
  }, 1000)
  
  return () => clearInterval(timer)
}, [])
```

### 2. 时区计算
```typescript
// 自动计算本地时区偏移
const timezoneOffset = -currentTime.getTimezoneOffset() / 60
// 生成 UTC±X 格式
const timezoneStr = `UTC${timezoneOffset >= 0 ? '+' : ''}${timezoneOffset}`
```

### 3. 日期格式化

#### 中文格式
```typescript
{
  date: "2025年11月07日 周四",
  time: "17:45:32",
  timezone: "UTC+8"
}
```

#### 英文格式
```typescript
{
  date: "Nov 07, 2025 Thu",
  time: "17:45:32",
  timezone: "UTC+8"
}
```

## 🎯 功能特性

### ✅ 本地时间
- 使用 JavaScript `Date` 对象
- 不依赖网络请求
- 实时准确

### ✅ 自动时区
- 自动检测系统时区
- 显示 UTC 偏移量
- 支持所有时区 (UTC-12 ~ UTC+14)

### ✅ 国际化
- 根据 i18n 语言自动切换格式
- 中文：年月日 + 周X
- 英文：月 日, 年 + 星期缩写

### ✅ 响应式
- 桌面端显示 (≥1024px)
- 移动端隐藏 (节省空间)

## 🔄 动态行为

### 1. 实时更新
- 每秒刷新一次
- 使用 `setInterval` 定时器
- 组件卸载时清理定时器

### 2. 语言切换
- 监听 `i18n.language` 变化
- 自动重新格式化日期
- 即时生效

### 3. 主题切换
- 颜色自动跟随主题
- Clock 图标使用主题色
- 时区徽章使用主题色
